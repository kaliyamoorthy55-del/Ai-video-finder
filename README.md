# AI Video Finder — Android starter app

A free Android search assistant for discovering AI video-generation and editing websites.
It does not generate videos itself and does not require an API key or paid search API.
Searches are opened in the device browser.

## Included
- Image-to-video discovery
- Text-to-video discovery
- AI video editing discovery
- Free-tier / unlimited-claim searches
- No-signup and no-watermark filters
- Search wording that asks users to verify official content policies

## Build on Android
1. Install Android Studio (official): https://developer.android.com/studio
2. Extract this ZIP.
3. In Android Studio, choose **Open** and select the extracted `ai_video_finder_android` folder.
4. Allow Gradle sync to finish. If prompted, install Android SDK Platform 35.
5. Connect your Android phone with USB debugging enabled, or create an emulator.
6. Press **Run** (green triangle).
7. To create an APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
8. Android Studio shows the APK location when the build completes.

## Use
Select one or more categories and filters, then tap **Search the web for matching tools**.
The app opens Google Search in your browser. Open official provider pages and verify their
current free limits, signup requirements, watermarks, queue restrictions, commercial rights,
and content policies before using them.

## Important limitations
- “Unlimited free” is not guaranteed; many providers offer limited credits or trials.
- Search results can be outdated or promotional. This starter app does not independently
  verify provider claims.
- No scraping, account bypass, paywall bypass, or API key is used.
- The app needs an internet connection to search.
- This is Android Studio source code, not a precompiled APK. Build it with Android Studio.
